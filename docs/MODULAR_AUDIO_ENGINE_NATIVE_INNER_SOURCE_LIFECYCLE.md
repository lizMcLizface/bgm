# Native inner source lifetime checkpoint B2a

B2a covers Native Tape's inner constructor, the NoiseGenerator and BitCrusher wrappers, and their four existing JS processors. It is a terminal ownership foundation. Noise/Crusher still execute their original JavaScript DSP; neither a clean receipt nor a constructor journal certifies a whole Instrument or a Rust source family. Backend selection and outer Instrument/Main ownership are unchanged.

Tape records twelve private actors, including four successfully started Native oscillators, before a later constructor action can fail. Failure starts every acquired cleanup and exposes cleanupReady without replacing the primary error. Terminal disposal is idempotent. The original 49-event Native constructor/control trace, healthy methods, constants and curve function remain exact. Fault tests cover every Native allocation, connection, start, property and automation position, including failures after earlier LFOs started.

Each Noise/Crusher wrapper owns at most two actual processor nodes, including current and retiring actors. Capacity is checked before type, active-state or amount changes which require another node; refusal leaves the existing current source and controls unchanged. Every actual AWP has its own SourceFence, sourceDisposalStatus and terminal receiver. Retiring nodes remain referenced until a clean acknowledgement; timeout, malformed/negative receipts and Native detach failures retain uncertain ownership. A late acknowledgement cannot change an already failed retirement promise into success. Source timeout is 1,000ms. Unknown or foreign nodes are refused without a fabricated receipt. Repeated retirement of a known node returns the exact original Promise, including after settlement; a WeakMap preserves this identity without retaining node keys. History is bounded to four data-only receipts; adjunct ownership is bounded to one private silent gain per ScriptProcessor.

The wrappers expose sourceActors() for inspection of actual nodes and disposalStatus() for aggregate diagnostics. Aggregate status is not a per-node capability certificate. Module observation is bounded to 10,000ms and can be canceled by disposal. This cancels only the owner's observation, not the context-global addModule task. Late load completion cannot create another node. The existing caches retain three Noise module registrations and one Crusher registration per context. Partial Node connection/setup failures retire the acquired actor and passive output nodes through cleanupReady.

The typed dispose handler first sets the existing stopped render guard, then replies with version 1, released:true, clean:true, renderQuiescent:true and heapFreed:false. This attests future JS-render quiescence on that exact port; it does not claim manually freed JS heap, physical listening silence or recovery of samples already buffered for delivery. Legacy string stop remains supported without inventing an acknowledgement for it. Every process body, RNG draw order and default unseeded Math.random behavior is preserved. Compact injected-draw golden checks cover full 60-quantum PCM and final draw state; they do not capture an old unseeded live voice.

The original ScriptProcessor fallback remains explicit. Disposal clears its actual callback and disconnects its Node and silent route. Its separate callback-closure receipt is not an AWP acknowledgement or a Rust DSP claim. Fallback DSP bodies are pinned unchanged. A selected portable environment must inspect actual actors and backend policy rather than assume a family label or an inactive current port proves future ownership.

The final focused dependency-closure run passes 241 tests across 28 files, including original operation/RNG pins, real processor-code host tests, constructor faults, late/negative acknowledgements, all Tape kernels/graph/resource/factory profiles and metadata guards.
