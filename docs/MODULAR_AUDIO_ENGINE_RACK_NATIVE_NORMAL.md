## Actual source and equations

Reference: src/synths/effects/extras.js, BUILDERS.width and BUILDERS.ring. Chromium e14de735f191c3a2bdce821a5e3f146bdc987b1e source hashes and required notices are recorded in synth-engine/rack-native-normal/CHROMIUM_PROFILE.json and CHROMIUM_NOTICES.txt.

Width owns four Gain AudioParams, with native constructor intrinsics [1,1,1,1]. Patch order is same-left, same-right, cross-left, cross-right, with four original currentTime reads. The native Float32 targets are (1+amount)/2 for each same gain and (1-amount)/2 for each cross gain. Left output is Float32(Float32(left*same-left)+Float32(right*cross-left)); right output uses right*same-right plus left*cross-right. The native splitter gives mono [mono,0]; Width always emits stereo. Sharing two curves is insufficient when corresponding original setter clocks differ.

Ring owns frequency, wet and dry controls in that order, with intrinsics [300,1,1]. Output is Float32(Float32(Float32(input*carrier)*wet)+Float32(input*dry)); targets are frequency, mix and 1-mix. Logical mono/stereo layout follows the input. The carrier uses the accepted native table/interpolation profile. JavaScript frequency.value=300 sets the intrinsic value and also books its same-value constructor step: the pinned IDL uses RaisesException=Setter, whose exception-state C++ setter calls setValueAtTime. Equal-time ordinary events append in the pinned InsertEvent; the later GUI step does not erase that constructor event. Constructor events do not count as GUI commands.

Initial patches use setValueAtTime; later patches use original20ms setTargetAtTime. Original clear is a no-op. resetNative is an explicit cold-native operation, separate from clear.

## Owned clocks and activity

The crate owns four bounded timelines, both program planes, targets, clock and carrier state. Each lane has256preallocated events. Render and updates/reset allocate or reclaim nothing. Rates are integer8000..192000Hz; canonical frames are multiples128 up to2^40-128. Authored seconds must equal frame/rate exactly. Ordered calls cannot precede origin or lie in the observed future. Late observed calls retain their authored seconds and native fresh-event first-pull semantics, with counters.

Three clocks are distinct:

- audio: evaluate native controls/carrier and process the declared program planes;
- parameters-only: evaluate controls and connected Ring carrier, produce zero program output and never read input planes;
- unpulled: advance the global clock while retaining control/carrier state.

The additive rack_normal_parameters_only ABI and OwnedNativeRackNormal.parametersOnly() implement the second clock explicitly. parameterOnlyFrames is separate from processedFrames and skippedFrames. Existing render(...,{demand}) behavior is unchanged: absent demand or zero channels selects unpulled. No flag is inferred from zero PCM.

This distinction follows AudioHandler::ProcessIfNecessary and GainHandler::ProcessOnlyAudioParams: a pulled native graph with silent inputs still evaluates its gain AudioParam and any connected oscillator. The actual extra-stage constructor includes an initially enabled outer input Gain; its silent mono bus can be pulled before a source connects. This is different from a disconnected graph or the subsequently disabled output of an ended source. A source's logical0channels must not be substituted for that physical native-gain activity. The ordinary owned wrapper also feeds its worklet through a native Gain. General native silent-bus inference remains excluded.

## Exact oscillator scheduling

Canonical context seconds can multiply slightly above their authored integer. At1664/44100, native startSeconds*rate is1664.0000000000002. Pinned TimeToSampleFrame first rounds the product to1/1024sample, then applies ceil, returning1664. The original positive fractional remainder is retained; OscillatorHandler advances its destination by1 and emits127samples, so the first non-silent sample is1665. OscillatorHandler initializes local frequency to0 on its a-rate path; the negative fractional-start adjustment therefore leaves its initial index0, and ProcessARate consumes phase increments starting at index0 rather than skipping its first entry. The constant path instead applies the native fractional offset and recomputes its partial endpoint with Float32 n*increment. A raw ceil of seconds*rate is not the native scheduled-source conversion.

The local oscillator.rs preserves the accepted table/interpolation/tick core and adds only these scheduled-start/index helpers. Its normalized upstream hash is recorded. Accepted shared piano live_sine.rs and all old rack kernels are untouched. Original seconds, destination offsets and partial counts are retained; no fitted epoch or PCM shift is applied.

The normal host uses32acknowledged stamped scalar records (289AudioParams including demand). It reserves a whole4/3setter call before mutation, preserves every original currentTime read, validates a complete contiguous stamped prefix, copies it into Rust and only then acknowledges it. Raw GUI values remain immutable f64 host settings; projected native targets are Float32. There is no native evaluated-curve bridge or MessagePort GUI timing substitution.

The loader verifies numeric and host manifests plus actual Wasm/processor hashes, shares one registration attempt per context and retries asynchronous or synchronous failure. Offline creation readiness does not wait for processor startup before startRendering. Original outer wet/through gains and host routing remain separate; a future whole-stage wrapper must propagate its outer output demand, because an inner connection to wet alone cannot identify chain removal. Bypass alone must not stop carrier phase.
