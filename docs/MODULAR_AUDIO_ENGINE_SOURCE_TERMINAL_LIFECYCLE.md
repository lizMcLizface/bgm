# Source terminal release contract

The old normal and prepared source wrappers could resolve disposal on a timer, close a MessagePort immediately after posting a request, or treat processor failure as release. A stopped runtime transaction cannot use those promises as ownership proof.

The new per-node sourceDisposalFence receives a typed one-shot terminal receipt (version1, released:true, clean Boolean) after processor resources/views have been released. Context closure is a separate positive proof. Missing receipt after1s or a processor failure rejects and retains a minimal receiver and context listener; the source remains quarantined. A late receipt records actual release without converting the already failed promise to success. Primary failures and independent cleanup failures remain visible. A positive release can coexist with an error; callers must assess both.

Known normal Core/FM/inserts, Native and owned CLASSIC, Native and owned Iowa, prepared owned Core/FM/inserts/FDN and role motion now expose node.sourceDisposalStatus() or owner.disposalStatus(). They retain pending control rejection and aggregate output/rack/limiter cleanup. Iowa waits for late preparation results and prevents installation after disposal; failed setup restoration awaits cleanup. CLASSIC startup cleanup awaits every acquired async owner and preserves the original error. Optional shared FM-bank proxies retain their prior prototype semantics and advertise no terminal authority; strict transactions must refuse them before mutation.

Processor changes are limited to terminal handling and typed receipts. Ten permanent pinned-original SHA checks prove their active bodies unchanged outside the declared terminal edits, including Native Iowa's new disposed guard. All four rebuilt legacy Rust binaries are byte-identical; owned CLASSIC/mixer reference refresh also verifies unchanged numeric binaries. No source tuning, scheduler, voice allocation, envelope or routing law was changed.

Verification:159 focused tests across14files pass, including direct actual-Wasm legacy/owned source and bus comparisons, all fourteen CLASSIC models, Iowa and role-motion, missing/wrong/late receipts, sibling independence, primary failures and paired limiter cleanup errors. The actual desktop fixed twelve-owner batch produced nonzero audio for every normal/prepared path and returned clean typed release proof, no quarantine/error and closed handlers. Receipt: reports/modular_audio/source-terminal-lifecycle-twelve-final.json. The earlier eight-path receipt is retained separately. Playback was muted after the analyser; physical listening and device deadlines are not assessed.

These are known source/bus owner fences, not automatic certification of every outer constructor or a completed all-Rust application. The next gate is actual detached candidate construction/cancellation with the existing Generator and its Transport/listeners preserved, followed by a Generator-owned synchronous publication/rollback binding and acknowledged retirement of captured old owners. No default backend switch is included here.
