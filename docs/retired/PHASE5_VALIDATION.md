Tonic pitches can still occur inside other chords: this bank is unresolved tonal writing, not itself fully atonal.

The atonal mode uses a deterministic twelve-class row with seeded transposition, inversion and retrograde; successive small pitch sets replace diatonic harmony, and all twelve classes are available to melody. It has no functional tonic/dominant cadence or tonic pedal. It is a pitch-set generator, not a strict serial composition system or a reproduction of a score. Bitonality currently has two fixed role groups: backing (pad/bass) and foreground (lead/second lead), using the selected scale at centres separated by 1–11 semitones. Foreground transposition happens before note-expression/connection planning; rhythm and within-group intervals remain intact. Arbitrary independent modes per individual voice are a possible later extension, not implemented here.

The first adds a chromatic semitone above the chord root in the upper octave; the second explicitly supplies the root's major seventh even on minor chords.
