## Normal integration contract

A new high-level adapter should compose the prepared source and spatial owners before touching shared environment selection. It should expose layer preparation, shape/level/wander updates, source contribution admission, authored fade commands, actual stop/cancel, start/stop bed fades, readiness and disposal. It must not expose invented AudioParam `.value` getters: Native main-thread getters read a last atomic intrinsic, while authored targets and actual audio evaluation are different clocks.

The actual normal seam is `Ambience.chain` and `loopSource` before their Native spatial/fade nodes. Weather supplies three separate stems; loop crossfades need separate source contributions. A useful bounded layout is ports0–2 for rain/thunder/waves and ports3–18 for up to16 independently owned loop cursors. The existing loop-bank pool has a context-wide16-cursor cap, so capacity exhaustion must refuse before replacing a playing source. Per-source cleanup must detach the underlying source facade and its demand, cancel only that owner, await its acknowledgement, and release its cursor before reuse. A new lease must not reconnect an ended/canceled source from an older ledger.

Original chronology must remain explicit: total wander is constructed at period180 in Brownian mode, then settings are applied; lazy layers capture their then-current constructor period, phase and offset. `start` can change the piece offset after total construction; this does not rewrite an already constructed wave. Live depth eases with the original0.4-second target, offline depth writes are property operations, start/stop gain commands and one-second loop crossfades keep their original authored seconds. Period edits affect only future undrawn knots. Queued asynchronous preparation must preserve original call order, and a canceled or superseded lazy recipe must release staging without changing an active source.

Finally, source activity must come from lifecycle plans or source-authored signals, never an amplitude threshold. Connected-zero and stopped/unpulled paths have different control clocks. Full owned-source composition and normal app/export tests must verify this boundary and the source endpoint policy before the common environment enables the new profile. Common environment, app routing and default selection remain parent-owned integration work.
