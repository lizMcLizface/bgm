# Legacy source and FDN ownership acknowledgements

This lifecycle change keeps the original percussion and FDN/echo Rust kernels, render loops, presets, hit mapping and control equations. It supplies the missing ownership fences needed by a future stopped Generator runtime transaction. It does not select a new environment in the normal UI.

The published percussion and effects processors announce `lifecycle-ready` version 1 with `disposalAck: true`. A valid disposal request has a positive uint32 request ID. Before replying, the processor drops its owned Wasm exports and PCM views; the receipt declares `released: true` separately from `clean`. A processing failure cannot remove the terminal disposal handler. A failed clear or cleanup still produces a typed negative receipt. Malformed requests do not retire the processor.

The host keeps its message handler and Node ownership through the matching receipt. Startup capability has a five-second deadline; disposal has a 1.5-second deadline. Timeout quarantines the owner rather than claiming release. A late receipt can release its references but cannot turn an already rejected cleanup into success. A cached processor without the new capability remains unverified and is refused by the strict stopped-bundle path; there is no Native source fallback. Ordinary creation timing is preserved: lifecycle readiness is a separate promise, not a new audio-processing wait inside creation.

Effects additionally report a distinct request-zero `end-frame` receipt for finite Offline rendering. It must match the declared finite frame range; its actual receipt is retained without inventing a matching disposal request. Live or premature finite messages cannot authorize release. Earlier processor errors remain diagnostic state while an independently clean release can still complete.

WasmDrumKit awaits the source receipt and every asynchronous room/routing cleanup, attempting all closures and retaining aggregate failures. FdnRoom owns pending bus creation: disposal prevents late bus attachment, waits its actual terminal receipt, drains tracked retirements, and surfaces asynchronous failures. `awaitDisposalCapability()` distinguishes an unbuilt room or verified bus from a legacy unacknowledged bus or fallback. Source acknowledgement alone never implies room acknowledgement.

Failed CLASSIC and Iowa creation now waits for disposal before rejecting. The primary error is retained with a separate cleanupError. Every successful member of a partially failed CLASSIC stack is closed. The Generator also retains its already-existing melodic duck Gain node in each role record, without changing a connection; this allows a future exact-edge transaction to name the post-fader source. No Generator, Transport or listener object is replaced here.
