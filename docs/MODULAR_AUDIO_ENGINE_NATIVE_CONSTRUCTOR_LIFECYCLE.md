# Native constructor lifecycle checkpoint B1

B1 adds private constructor and terminal cleanup ownership to Oscillator, LFO, Flanger, Chorus, Phaser, Motion and MonoSynth. It is accepted as a lifecycle change. It does not admit a whole Instrument or physical source family into Main, change backend selection, or establish universal Native feedback PCM parity.

Each constructor immediately records its returned private actors in a bounded journal, preserving Native creation, parameter, connection and start order. Failure starts every acquired cleanup action and exposes `error.cleanupReady`; nested cleanup and primary errors are retained. Successful oscillator starts are recorded so terminal cleanup stops actual started sources. Native disconnect during ordinary routing keeps its original behavior. New terminal methods are idempotent and attempt sibling cleanup even after another actor fails. A journal callback completing is not an AudioWorklet termination capability or source-ended acknowledgement.

MonoSynth's later duplicate `destroy()` previously overrode the fuller destructor. Its single terminal method now disables auto-resync, clears note/hold timers, closes current private string/FM actors and retires its constructor actors. It does not invoke noteStop(), which could book a new hold timer. The normal Instrument disables auto-resync during synchronous initialization; arbitrary standalone manual/auto-resync histories remain outside B1 certification. Shared modulation sources and whole Instrument ownership remain their parent's responsibility.

Native string cleanup uses one explicit action over the existing finite source Set, rather than one journal action per note. Every stop and disconnect is attempted, successful owners are removed and uncertain owners remain. Error detail is bounded to 16 with total/omitted counts preserved; no new note cap is imposed. The 300-source regression includes 600 failed actions and retained uncertainty. This Native action receipt explicitly does not acknowledge the audio-thread source-ended event.
