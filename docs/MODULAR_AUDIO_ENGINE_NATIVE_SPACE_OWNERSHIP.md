# Native VoiceCompressor and Space ownership

The Native VoiceCompressor, Shimmer and Freeze wrappers now own each private actor before its first fallible setup operation. This is a lifecycle correction. It does not port Freeze DSP to Rust or admit the complete Instrument family to Main.

VoiceCompressor journals its actual DynamicsCompressorNode and makeup GainNode. Cleanup attempts both disconnects immediately, aggregates failures and returns the same retirement promise on repeated calls. Its original settings, automation and makeup arithmetic remain unchanged.

Space journals its two private gains and creates a bounded per-node terminal owner when its lazy AudioWorkletNode is returned. Cancelling a wrapper cancels its observation of the shared module request; it does not cancel another wrapper's load. An observation has a 10-second bound. A failed or late module retains the existing dry fallback and cannot revive a cancelled wrapper. A node-construction or setup failure joins known gains and any returned processor before reporting cleanup. This readiness promise describes module/setup observation, not a processor initialization acknowledgement or Rust-DSP capability.

The original JavaScript processor accepts a version-one terminal request. It stops accepting settings/clear messages, returns zero output and `false` on subsequent process calls, and acknowledges `clean:true`, `released:true`, `heapFreed:false`, with scope `javascript-processor-terminal-quiescence-v1`. This proves JavaScript terminal quiescence; it does not assert immediate garbage collection or manual freeing of its arrays. A negative or missing receipt remains quarantined under the existing SourceFence. The wrapper holds at most one current and one retiring actor; its released history retains at most four data receipts.

Instrument cleanup delegates to these actual owners. A foreign or manually substituted Space node cannot acquire terminal authority from its label: known private actors still retire, while the unknown node is refused without being disconnected or having its port closed.
