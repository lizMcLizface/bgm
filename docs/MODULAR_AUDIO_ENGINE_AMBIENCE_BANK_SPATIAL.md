# Owned loop bank to complete Ambience processing

`ambienceBankSpatialSource.js` is a new, opt-in composition adapter. It does not edit the accepted bank/session prototypes, source kernels, normal Ambience or prepared environment. Its accepted bounded successor is `9ae3cf1dd2173cb8`, depending on accepted session32a2 and the separately versioned bank. Both actual browser receipts are retained below. Existing Native defaults and offline immutable playback stay unchanged.

The factory accepts a prepared same-context bank lease, an already prepared spatial session/layer and optional abort signal. Wind/fire/vinyl retain their actual material-to-layer mapping2/4/5. Each source gets one private unity bridge. The source facade's all-edge disconnect is therefore never mistaken for Native selective disconnect on someone else's edges. Preparation is asynchronous and must finish before playback; start/offset and repeated stop calls then forward unchanged to the existing reader. The adapter does not regenerate, replace, resample or normalize PCM.

The raw cursor belongs only to this adapter. Before playback it installs a per-instance disposal fence, retaining the original cursor dispose method. The actual BankSource.end() dynamic call therefore enters the fence. Retirement disables source demand, awaits actual spatial owner cancellation and activity ACKs, then invokes original cursor disposal/free. Only after that physical ACK can the allocator reuse the slot. End notification follows retirement. Repeated dispose returns the same promise. An uncertain spatial cancellation leaves the cursor occupied and muted; it is not silently recycled into a still-bound input. Context owner teardown handles uncertain ownership. Other sources and bed leases remain independent.

Seven permanent tests use the actual accepted bank and spatial host/worklet/worker code with real Wasm. They verify automatic end against a deliberately delayed spatial acknowledgement; bit-exact independent cursor PCM while another source retires; occupied muted quarantine after failed cancellation; pre-mutation material/context rejection and private-bridge constructor failure; completed rollback after cursor construction/readiness failure; actual timeout and late-ACK quarantine; and pre-mutation rejection of invalid retirement budgets. The private reader's source generation, fractional onset/offset/wrap/stop semantics and16-cursor context quota remain the accepted bank contract. No new render allocation claim is made for host JS objects.

The actual grouped review checks original untouched JS vinyl PCM channel SHA against the verified bank resource before audio starts. Two independent complete beds share that bank resource. The fence deliberately holds the old physical slot; another cursor must use a different slot, and the old one may be reused only after acknowledged cancellation with a fresh token. ## Source endpoint and demand plan

Current accepted session composition covers continuously supplied inputs. Its activity derives filter/layer/bed demand from incoming contributions. This has not proved the same behavior as a connected Native chain with no current audio source. Native ProcessOnlyAudioParams can still pull modulation and update retained intrinsics during connected silence. Losing the final source can also leave genuine IIR tail samples; disabling the entire layer at that instant may cut them. Complete output disconnection is a different clock and is already covered by independent pull-gap evidence.

Before choosing a new policy, the separate unchanged-candidate diagnostic uses two fresh48k contexts. It sends exactly the same Native stereo source into both processors, with no LFO taps that would force otherwise absent demand. One case leaves a connected chain silent before its first source. The other stops and disconnects the final source at a common epoch, leaves the chain connected through idle, then restarts it. Actual level/depth intrinsics, authored epochs, explicit masks and full audio are recorded. This is a causal before-proof rather than presumed acceptance.

A possible successor policy separates outgoing bed demand, constructed layer/control demand and actual source contribution activity. Constructed filters/controls can remain explicitly demanded during the bed's connected lifetime, receiving zero input after the final source ends. This retains natural filter decay without PCM-amplitude classification or an invented Native handler-disable timestamp. Actual sources can still be canceled and their cursors ACK-freed promptly because the retained filter belongs to its layer, not the cursor. Complete downstream disconnection must freeze pull-dependent clocks and source demand; rejoin must preserve the measured Native control history law.

That policy is not yet implemented or accepted. It must pass the same fixed1e-7 full-audio bound through delayed first input, stop/idle/restart and complete unplug/rejoin, with no output shifting, tail trimming or widened tolerance. It must also preserve future controls, stop overwrites, first-Brownian preparation, independent handles, source generation fences and original scheduling. Native fan-in Float32 order and historical Native filtered endpoint bit variability remain explicit; a new owned policy cannot claim their bit identity without evidence. Automatic15-second refill timer ownership, configuration replay and normal live/offline app adoption remain separate work.
