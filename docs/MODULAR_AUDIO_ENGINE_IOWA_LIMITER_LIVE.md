The original IowaPlayer constructs a bare DynamicsCompressorNode, then assigns threshold=-6, knee=6, ratio=12, attack=.003 and release=.15 through intrinsic .value writes, in that order. This is distinct from Nodes.Compressor, whose constructor first assigns .005/.05 and whose setters use setValueAtTime. Native .value writes update intrinsic state and append their native SetValue events. The owned limiter therefore requests profile:'bare-native' and exactly five immutable initialProperties pairs. It does not substitute wrapper events or approximate this as a final settings snapshot.

The prepared synchronous context-bound factory supplies only the limiter node; original bus/dry/wet/convolver/master routing, complete impulse and source algorithms stay intact. Missing/invalid factory output rejects and disposes the acquired stage; it never silently falls back. Creation-only stage.ready joins player.ready, while health/arm waits are explicit and cannot deadlock suspended/offline construction. The factory remains runtime configuration, never song/source setup data; restoreSetup accepts it in a separate third options object.

A direct player.connect defaults to demand-on and can explicitly override it. Connected idle retains native silence/tail processing; note-state activity does not invent a new sleep policy. Disposal closes the source and limiter independently and retains acknowledged cleanup. Limiter failures are visible in sourceStatus and refuse new source messages.
