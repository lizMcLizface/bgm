## Source and clock authority

`preparePhysicalClockedSources(context, {clock})` takes an explicitly running live context and its already prepared Native7a provider. It returns context-bound `pianoFactory`, `pluckedFactory`, `create(material,instrument,{signal})` and read-only quota information. Each factory returns only after both the actual material/rate/voice initialization ACK and independent Native-clock/same-source-FIFO admission. It neither resumes the context nor owns/disposes the shared clock provider. Offline and foreign/suspended contexts are refused.

Every actual Node gets a fresh anchor receipt immediately before construction. The Processor uses a separately prepared, untrusted startup decoder; the strict render ledger remains unbound, and Rust does not render, during that phase. After its first candidate, the host obtains a fresh independent Anchor snapshot and waits for a same-source FIFO preview at least as new. Only an explicitly admitted, subsequently observed vector binds the strict ledger. Another same-source FIFO proves the actual generation/frame and absence of pre-publication program notes. A stale zero-coarse eight-second alias never advances the strict ledger during preview. Startup default fields have a declared 64-callback bound; factory admission and registration observations are bounded, not success by timeout.

The admitted ledger requires consecutive actual 128-frame Native vectors. It does not infer time from global `currentFrame`, clamp a decoded epoch, synthesize omitted DSP samples or replay an earlier output. Suspending/interruption retires the shared Native generation; this live-only profile does not preserve the old player's separate suspend/gap policy.

## Render and ownership boundaries

The generated controller and Processor are mechanically checked against exact accepted source hashes. Only registration, clock admission, lifetime ownership and diagnostics differ. Original note/control/preparation/action/terminal and render math remain pinned; all piano and KS resources use the existing original Rust preparation. The new manifest references the existing 253,652-byte numerical file, SHA-256 `809dc82c710d67635002ec8145f6870da4ddbb89e229d0ca2a2b570744fcf308`. No duplicate Wasm or replacement sound is published.

Each actual source Node has one zero-output private pull and its own typed terminal fence. `hostAwake:false` still suppresses Rust DSP and source-age advancement while Native callbacks continue. Program routes use explicit destination leases; retirement closes only those known edges. It never calls source `disconnect()` without a destination, which would remove the private pull before terminal proof. Clock links/private pull retire only after that Node's actual typed release ACK or context closure. Shared-provider generation retirement remains a separate provider-wide event.

The context quota is 16 creating/owned/uncertain physical Nodes; the seventeenth is refused before source construction. Program edges are bounded at eight distinct same-context destinations per Node, and FIFO requests at 16. Failed/unconfirmed release retains its reservation and uncertainty; a late receipt may release physical edges but cannot change an already rejected disposal into success. Only a specific `InvalidAccessError` for a previously recorded exact edge is reported as an already absent known edge; other failures remain errors. Context history retains at most 32 data-only receipts. Each source retains the accepted 24MiB prepared-bank cache and original bounded voice/control/resource contracts. This host change makes no new claim that bank preparation/upload is allocation-free or deadline-safe on the audio thread.

Creation supports explicit request cancellation. It joins actual preparation cleanup and Node terminal acknowledgement before returning a known-clean failed admission. Module observation bounds only this owner's observation; it does not cancel a context-global `addModule()` task, and late completion cannot construct a Node. The caller continues to own its instrument and context; the factories do not certify or clean unrelated Native construction.
