# Main control root and authoring integration

The new Generator-owned control root is an explicit cold-session boundary.
It accepts only the new raw-frequency six-role profile, matching constructor
volume/initial-target recipes, and a retained Source7a session lease before the
first Native wake. It exposes program destinations only after all role arm and
activation receipts. It retains the original compatibility objects, detaches
their program edges, and journals attempted logical/physical route changes.
There is no automatic fallback after quarantine.

Prepared source replacement and editable source slots resolve the stable root
input/output through shared helpers. A stopped snapshot rejects a control-root
change during preparation. Suspended-born Source7a is accepted only with the
registered root's immutable certificate tied to the actual private controller,
group generation, configured zero origin, six actual first-frame-zero receipts
and current activation; the ordinary running-clock requirement stays intact.

A shared registry lease owns the clock controller itself. Metadata consumers
only own their wires. A candidate borrows the root until every actual candidate
actor finishes teardown. Failed or uncertain cleanup retains that borrow.
The root releases its clock session only after actual group terminal release.

Pure authoring plans preserve the original mix/solo/played-live and tone law.
The author reserves a complete batch before mutating role/settings/tone state.
Combined volumes/muted settings retain the two original mix waves and require
an explicit global publication order. Duck batches retain release extension
and run their booking continuation only after admission. A failed reservation
is retryable with unchanged parent state; partial publication is terminal.
Separate room-return controls are explicitly refused by this first scope.

Verification: 108 focused tests in ten files pass, including the existing
stopped/editable routing tests, attempted-connect rollback, delayed and failed
actual-owner cleanup, clock references, strict cold certificates, whole-settings
capacity failure and original mix/tone trace comparisons. These are unit and
integration checks with injected actors, not a new actual AudioWorklet PCM gate.
The six-rate actual nominal control/cold-start evidence is documented separately.

Current limitation: Generator's normal methods do not call the new author yet.
The explicit raw-frequency six-role host and its ordered writer/certificate are
being integrated separately. The next step is to wire these selected branches,
then run one grouped actual Generator source/FX/mixer/swap/reload review. Existing
application defaults, old nominal validators and numerical kernels are unchanged.
