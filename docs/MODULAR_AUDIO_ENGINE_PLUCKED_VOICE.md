# Prepared generator plucked voices

This extends the standalone actual Karplus–Strong preparation into a separate
finite plucked voice contract. It does not identify plucked material as a piano,
replace the native generator, or move shared effects/mixer processing.

## Actual native boundary

The native path is `Instrument.scheduleNote` → `MonoSynth.scheduleNote` → native
AudioBufferSource → source gain2.5 → per-voice gain envelope → per-voice Biquad →
volume0.2 → `Instrument.synthMix`. The existing synthMix compressor and shared
colour/rack/limiter/output chain remain after that seam. Its existing
`holdSourceInput()` lease already keeps the shared chain awake without waking
the legacy oscillators; a new private wrapper seam is unnecessary.

String material bypasses the modelGate formant-filtered source branch. Independent
air generated by BreathFormants can still enter the gain envelope and must not
be discarded. The initial capture explicitly rejects active breath, held keyboard
notes, future native bookings, nonuniform per-slot filters/gain and non-lowpass
filters. It captures actual configured filter values rather than a suspended
AudioParam's potentially stale platform defaults. Static formant amount does not
apply those filters to the plucked material and is not invented on the new path.

The allocator is round-robin among voices free by the requested onset; otherwise
it replaces the earliest busy voice, with first-slot ties. Busy time follows the
gain envelope's release end, not the finite buffer end. Stealing cancels/holds
the prior envelope10ms before the new onset and eases it toward zero with2ms tau.
The new finite compiler reproduces that planned fade and preserves filter history
per slot. It rejects same-slot steals closer than10ms, late-onset shifting and
arbitrary live note expression instead of silently approximating them.

The native source has a wall-clock stop at the earlier of its original prepared
buffer duration and gain-envelope end. This remains true under negative detune;
slower read positions must not extend it. The new voice retains that stop as well
as the source's natural earlier exhaustion under upward pitch movement.

## Portable contract and implementation

`synth-engine/plucked-voice` owns KS sample banks, immutable finite note plans,
per-slot source cursors/filter histories and bounded output. It depends on the
actual plucked-string preparation crate. Its bank identity/settings are explicitly
plucked; no piano renderer or piano bank IDs are used. It reuses the existing
immutable numeric control primitive from `piano/src/control.rs`, and derives its
finite envelope/filter/cursor machinery from the established finite-voice adapter.
This is mathematical reuse, not a source substitution.

Initial voice rate is explicitly48kHz. Limits are32 voice slots,2000 notes,
128 banks,64MiB total prepared PCM,65536 gain/filter points, four captured shared
control axes and128 points per shared control. Preparation checks the material
budget before generating temporary PCM. Render/cancel/reset allocate/free nothing.
The standalone host ABI is `plucked_voice_*`, API1. The rlib's `Engine` exposes
bank/note/point/lifetime/control preparation, valid/note/cancel/reset/stat/render
for later Graph integration. Source timestamps are explicit sample frames;
pitch detune uses the absolute128-frame k-rate clock, filter control remains
sample-rate and oscillator/random-walk captures retain their actual phase/shape.

`pluckedStemTap()` returns `kind:'plucked'`, existing synthMix input, immutable
source settings/tuning/envelopes/control snapshots, guards and chain-awake lease.
`compilePluckedNotes()` creates version1 explicit banks/notes/slots/lifetimes,
original gain/filter plans, owner/timestamp events and finite tail allowance.
Unsupported note-local expression fails closed. Each source bank retains actual
0.01Hz cache pitch quantization. Config is independently validated and persisted
with `savePluckedConfig`/`loadPluckedConfig`.

`OwnedPluckedVoice` owns a fresh prepared host, replays its immutable planned
events across arbitrary copy-block partitions, supports owner cancellation and
reset, and rejects stale Wasm views after another preparation grows memory.
The loader caches immutable compiled code and returns fresh memories. The native
shared compressor/rack/master chain is excluded from the standalone voice output.

## Evidence and remaining acceptance

Production build `d5cf3e9a8f1664d7` is86,381bytes. The separate counting-
allocator build `0e3d80138578ca5e` is88,202bytes. Seven permanent tests cover typed
capture/compilation, native envelope/filter plans, partition invariance, exact
save/reload/reset, same-memory independent handles, owner cancellation and bounds.
Twenty-four numeric two-instance cases cover four body profiles,1/2/8 slots and
captured sine/linear pitch/filter modulation. Twenty-four allocation cases report
zero allocation/reclamation calls and no memory growth after preparation.

Those numeric/allocation facts are supplemented by actual browser evidence. The
`tools/plucked-voice.html` harness compares the actual Instrument/MonoSynth dry
voice before its shared compressor/FX against the portable source using real
OfflineAudioContext output. It covers five actual library plucks, one-/two-slot
stealing, positive and negative pitch envelopes, vibrato/filter LFO and sine/
Brownian wander. Its fixed acceptance limits match the established piano voice
comparison: relative RMS error below0.005 and correlation above0.99998. Source
resampling/Biquad numeric parity is approximate, not bit identity.

All12 actual native cases pass on production `d5cf3e9a8f1664d7`; worst relative
RMS error is0.0003977205027305308. Presets and acceptance limits were unchanged.
Evidence is `reports/modular_audio/plucked-native-browser-v3.json` and its PNG.
This is muted OfflineAudioContext comparison before shared effects, not device
deadline or physical listening evidence. No new phone acceptance gate was added.

### Measured native pitch-clock correction

The initial native comparison exposed two genuine pitch-envelope failures while
the other10 cases passed. Its original report/screenshot and v2 attempt remain
in `plucked-native-browser.json` and `plucked-native-browser-v2.json`/PNGs; they
were not overwritten or reclassified as passes. The initial version applied a
target amount in the first partial render quantum. A first correction kept that
partial quantum at the parameter's default0 but still aged the exponential from
the precise note onset. Both rules were incomplete.

The independent muted `plucked-pitch-probe.html` harness measures actual native
AudioBufferSource read position using an encoded linear ramp, with the same
source creation/suspend origin1024 and setValueAtTime/setTargetAtTime/start/stop
calls. No Rust, plucked material, envelope or filter participates. Sixteen cases
cover onsets37/128/6000/30000, amounts300/-600 cents and decay0.2/5seconds.
`plucked-native-pitch-probe.json` retains the complete measurements, including
matching k-/a-rate ConstantSource controls; the BufferSource position is the
authoritative measurement because nonaligned ConstantSource controls differ.

Measured law: an initial partial quantum stays at default0 detune. The first
full absolute128-frame quantum receives the exact initial amount; the complete
target-decay clock begins there. Subsequent quanta age by128 samples. Thus the
target epoch is `ceil(sourceStartFrame/128)*128`, not the exact onset. For onset37,
the first91 source samples use rate1; the next128 use `2^(amount/1200)`, followed
by the amount decayed over128 samples. Onset6000 has the same first full value
after its16-sample partial quantum. An aligned128 onset begins immediately.

The owned cursor now follows that measured epoch. Read-only stat9 exposes the
first slot's cursor for regression diagnostics without changing its PCM/state.
A permanent16-case test compares source cursors against the actual saved native
ramp traces, including positions at each quantum's entry/last sample, within
0.02 sample (encoded Float32 measurement tolerance). Native voice acceptance
then passed all12 original cases with the original0.005/.99998 limits.

Distinct Graph26 `legacy.plucked`, preparation ABI and All workbench/tap paths
are implemented as an opt-in source preview. Existing shared compressor/FX and
native defaults remain. Mixed worker coverage retains the protocol's five
pitched buses plus percussion6; four independent classic mono kernels, a stealing
plucked source and Hand drums have exact PCM against independent serial sources.
Graph ownership/planned-onset preparation and duplicate/late queue checks have
their own focused tests; publication/integration checks remain parent-owned.
