# Main stopped-runtime publication

This new, unselected binding updates the owners of one stopped Main Generator. It retains the Generator, Transport, role containers, settings, plan/listener Sets, tone/gain/duck nodes, master fade/sweep and level trim. It does not select a new UI default or copy another Generator's fields. All desk routes require their own binding and are refused here.

The transaction first builds detached owners through the existing candidate component. It rechecks settings, presets, revisions, current owner identities and source/control terminal capabilities before Native edge mutation. Active master/end fade timers and the separate standalone MIDI owner are refused before wake; they are not silently left outside this six-role transaction. An actual source port without a healthy typed release contract is refused. The optional FM-bank policy is refused before wake or construction; no source algorithm is substituted. An unexpected untyped actor that arrives despite admission is closed as far as its API allows and retains explicit cleanup uncertainty. Direct physical constructor paths and global shared room owners remain outside this profile.

The Main binding removes and adds only exact captured Native edges. Original Ambience connects its final `wanderOut` to Main; its internal `output` is the sum before total-level wander and is not a destination edge. The first Main2 desktop attempt exposed this distinction by rejecting the incorrect disconnect. That negative remains `reports/modular_audio/main-stopped-runtime-main2-first-negative.json`. Main3 journals the source-derived final output; missing Native edges remain hard errors with operation/index/semantic-label diagnostics. A source's logical connect remains authoritative: a sleeping percussion source records its destination without inventing a physical edge, and Iowa activation uses the original host-awake contract. The candidate's logical connections are completed before targeted owner-pointer publication. A later connection or publication failure reverses those candidate activations, restores exact prior pointers/property presence and reverses the completed Native edge journal. Captured old owners are retained until that synchronous publication succeeds. Failed reversal quarantines the transaction; it cannot be reported as a restored runtime.

Returns remain explicit. An original Main bus is connected directly to the old Main output. A published candidate's bus and Ambience reach Main through candidate-owned private return nodes. The binding retains that routing authority in a WeakMap keyed by the existing Generator. This is routing metadata, not an inferred resource lease. `commitMainStoppedRuntime` waits for explicit registration of the returned published scope before resolving caller readiness. Registration correlates the scope's actual published value with this binding, not merely context/state. Missing scope registration refuses a successor before mutation. A registration failure after publication retains the actual published scope and a typed quarantine; it never claims old owners returned after retirement began.

Successor bindings capture the exact private return edges and previous explicit scope. Synchronous rollback restores the previous routing authority. Successful replacement awaits captured old source/Wander/shared-owner closes and retires that previous scope, including its explicit upstream leases. After successful retirement it drops the previous authority link, preventing a chain of retired publication scopes from being retained by successive bindings. It never calls `disposeSharedEffects()` after installing new pointers. Source timeouts, primary failures and negative terminal health remain failures even if a later receipt proves release.

The published owner is still the caller's responsibility. The caller must await `previousRetirement` before allowing playback. `detachPublished()` is a terminal-only operation: it disconnects the candidate's exact Main edges and logical destinations, then the caller retires the published scope. It never reconnects already retired old owners and refuses to detach a foreign replacement.

The first Main profile admits an existing Ambience that has no active/pending sources or unresolved fade ownership. Previously started legacy Native weather without an explicit terminal release authority is refused even if its running flag is already false. Complete Ambience has a separate explicit cold bootstrap and asynchronous prepared-start contract. It is not silently routed through the old synchronous Ambience interface. No complete-session, Native PCM identity, physical listening or callback-deadline claim follows from this component.

Sixty-nine core checks pass across the Main binding, source authority/snapshot admission, detached owners, reservation transaction, control warmup and engine-switch retirement. Sixteen adjacent environment/shared-route checks and the172 existing Generator regressions also pass (257 total). They include first and successor publication, correlated scope registration, exact private returns, captured prior-scope retirement, sleeping logical source routing, source activation rollback, old-owner retention, exact pointer restoration and quarantine. The narrow existing `setAudioEngine` path now tracks and awaits each captured old source at its original per-role retirement point, including a later connect failure, and aggregates stale/failed candidate cleanup without replacing the primary error. It retains its existing legacy partial-switch semantics; the new transaction provides the stronger exact rollback contract.
