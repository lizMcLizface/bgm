# Music generation improvement plan

At the end of each implementation slice, report the current phase, what remains in that phase, and the direct next step.

Created 17 October 2026. Status: Phase 3 implementation is complete locally, with five form strategies, shared subdivision/tension curves, harmonic pacing/destinations and ending/boundary integration. Phase 1 is complete, and Phase 2's shared rhythm, duet/counterpoint and breathing layers are implemented; its optional timeline refinements and broader percussion listening remain open. Scene-aware sounds, damped strings, struck keys and phrase performance are available. Listening review and constrained-device checks remain evaluation gates. The progress record distinguishes implementation from listening approval.

Build stronger musical identity and development while keeping calm background listening, browser synthesis, live editing, reproducible seeds, and offline rendering. Prioritise memorable themes and coordination between parts before adding more sound effects or random variation. Apply the improvements to the existing preset library by default. Existing vibes and exact seed output may change; preserving every previous result is not a release requirement. Presets should still have distinct musical behaviours, and more sophisticated generation must also work with very few notes. An explicit Original generation option will provide access to the previous algorithms.

## Implementation progress

First slice implemented on 17 October 2026:

- The options menu selects Latest or Original. Latest is the default for all scenes; Original persists as `generation=legacy` in preset and settings URLs, copied links, reloads and mode navigation. Mode changes use the next chord while playing. Copied setups and offline render settings carry the mode. New sound recipes are not part of this slice; both paths still use the existing synthesis and sound generators.
- Original arranger and percussion functions are unchanged. Three 48-bar reference fingerprints cover 4/4, 3/4 and 6/8. Existing generated-sound version snapshots also still pass.
- Latest has meter-specific percussion anchors, explicit 4/4 full-time backbeats, a deliberate downtempo half-time variant, and three groove variants per style. Structural anchors are protected, fills reserve the final felt beat, duplicate same-drum attacks coalesce, and ornament choices share a budget. Timing variation is partly shared across a felt beat, keeps initial anchors exact, and has no extra velocity jitter when looseness is zero.
- Latest retains two themes through silent phrases. Four-bar statement, answer, development and return plans reuse degree-and-rhythm motifs; harmony parts follow the resulting melody. At this stage, pitch realisation used a bounded 12-path search within each bar, with register, contour, chord-fit and closing-note costs. Eight-bar phrases and joint counterpoint remain to do; phrase-wide search is added in the ninth slice, while bounded transforms are added in the eighth slice below. The pentatonic lead option is now strict in Latest; Original keeps its previous behaviour.
- `tools/percussion.html` provides a local listening harness with direct selection of every Latest groove, all meters, tempo, seed, swing, timing and ornament controls. It renders dry four-bar WAV loops and prints labelled events. Original remains seed-selected and retains its built-in stochastic choices. This enables the audit; it does not mean every groove has passed a listening review.

Fifth slice implemented on 17 October 2026:

- The initial string model uses a Karplus–Strong delay loop with damping, fractional-delay tuning correction, deterministic pluck-position excitation and an external damped body resonance. A triangular initial displacement plus a small noise component keeps a ringing fundamental; the loop gain is capped below unity. Output is DC-filtered and bounded, with a calibrated input level in the instrument. This is a foundation, not a complete acoustic instrument model.
- String note buffers are built ahead of their audio-clock start and shared through an LRU cache capped at 24 MiB. Individual buffers last at most six seconds. The existing gain/filter envelope, role polyphony, stealing fades and effects chain handle them. Note cancellation stops queued sources; held-key release stops the source at its release end. Microtonal tuning, per-note detune, pitch envelopes, vibrato and pitch wander are supported.
- Latest applies the model to named Nylon Guitar, Soft Harp, Harp Pluck, Kalimba Pluck and Upright Pluck patches and to v3 generated folk plucks. Folk winds stay on the oscillator path. Known limitations to address:

- Motifs store rhythm and movement instructions; their exact pitches are reconstructed from the current harmony and previous pitch. A repeat does not necessarily reproduce a recognisable melody. A resting lead phrase loses the existing repeat mechanism's motif memory.
- Lead rhythm comes from a small set of group cells, with repeated held closing gestures. Bass, accompaniment and drums have little shared rhythmic planning.
- Sections mostly change role participation, activity, accompaniment style and cutoff. They do not retain themes or plan a multi-section musical arc.
- Walking bass chooses mainly root, third and fifth plus an approach. Counter harmony is principally a diatonic third, without joint voice scoring.
- The pentatonic lead option only restricts scale-step notes; strong notes and resolutions can still fall outside that pentatonic set. Pentatonic harmony also stacks alternating notes from the five-note scale, producing colours that may differ from a folk preset's intended harmony.
- Generated sound recipes receive role, kind and seed or ensemble character, but no scene identity, tempo or expected articulation. Named acoustic sounds remain oscillator/filter approximations.

## Design constraints

- Keep music and sound generation procedural and local. Preserve the app's current absence of recorded instrument samples and generative model dependencies.
- Keep composition planning separate from the audio scheduler. Run bounded searches ahead of playback; do not perform them inside audio callbacks. Measure planning alongside the WebGL visualizer.
- Carry all musical state in serialisable plans. Replanning, rewind, looping, offline render and restore must produce the same events for the same version, settings and seed.
- Separate random streams for form, harmony, motifs, rhythm, pitch, performance and drums. Enabling one optional layer must not reshuffle unrelated material.
- Preserve manual settings, mute/solo, user-selected sounds, and the simple progressive interface. Profiles supply defaults and scoring weights rather than silently overriding explicit controls.
- Use improved generation by default for new visits, existing scene presets and links without an explicit generation choice. Do not automatically route old links to the old engine or require exact old seed output in Latest mode. Keep the original algorithms available through the explicit mode described below.
- Keep link payloads decodable: do not corrupt or reinterpret the existing bit layout when adding sound kinds. Preserve the baseline composition, percussion and sound recipes for Original mode, rather than freezing all future default behaviour. Rendering old generated-sound seeds through improved recipes in Latest mode is allowed.

## Percussion audit and repair

Priority: early work after the baseline capture in Phase 0. This review can proceed independently of theme and phrase planning; awkward percussion should not have to wait for the larger composition redesign. Treat every shipped groove as a musical choice to evaluate, rather than assuming the existing pattern bank should all be retained.

The current code suggests several places to investigate. These are candidate causes, not listening diagnoses:

- `geometry()` derives backbeats from later beat-group starts. In 4/4 this produces a backbeat on beat 3, rather than a conventional beats 2 and 4 pattern. Half-time is valid, but each style should deliberately choose its feel instead of inheriting one shared mapping. The 3/4 fallback and 5/4, 6/8 and 7/4 groupings also need style-specific review.
- `drumBar()` can combine groove substitution, phrase-level instrument swaps, alternating-bar twists, dropped hits, ghost notes, fills and Sprinkle. Their combined effect may be much less restrained than any individual probability suggests. Dropping a hit protects its insertion position rather than its musical role, so a structural kick or backbeat can disappear.
- `fill()` adds events over the existing groove. Check doubled attacks, competing accents, overly long rolls and the arrival into the next bar. Verify the intended clap, rim, brush and tom choices against what is actually emitted and heard.
- `loosenDrums()` applies independent timing offsets and clamps early hits at the bar start. Check downbeat bias, kick and bass separation, clustered attacks, and the extra velocity variation that remains even with the user velocity setting at zero.
- Drum envelopes, brush sweeps, pitched toms and cymbal tails can make sensible event positions sound awkward. Review pattern and kit sound separately, including the felt-to-crisp mapping.

Plucked-string synthesis is a foundation rather than a complete acoustic instrument model. Keep the existing oscillator path as a lower-cost option. Benchmark each addition with actual polyphony, active effects, fluid rendering and offline export before broadening its preset coverage.

## Listening and release gates

Use the same settings and seed on both engines, with matched levels. For sound comparisons, keep the notes fixed; for composition comparisons, keep the sounds fixed. Judge short excerpts for phrasing and multi-minute renders for development. Include longer background sessions to catch fatigue, density creep and repeated transitions.

| Evaluation scene | What it should demonstrate |
| --- | --- |
| Same Tune, Slightly Different | Theme recall through changing harmony and rests |
| Five Notes Only | Explicit pentatonic behaviour and restrained development |
| Fireside folk and Turnip Town | Folk phrasing, accompaniment interaction and acoustic character |
| Rainy café and Late-night brushes | Convincing lo-fi and brush grooves, expressive keys and connected bass |
| Percussion review fixtures | Every retained groove, explicit full-time or half-time feel, all supported meters, clean fills and restrained default embellishment |
| Boss Fight, Politely and Heroic Field Trip | Strong thematic identity and prepared contrasting sections |
| Oxygen Debt | Persistent sequence development without constant pattern replacement |
| Replicant Blues | Long expressive gestures, harmonic direction and swells |
| Deep night and Open Mic Pad | Sparse, calm behaviour without unwanted busyness |
| Sunrise in seven and Quiet-room waltz | Odd-meter and triple-meter behaviour |

For each release increment:

- [ ] Run meaningful unit and integration checks for deterministic plans, bounded ranges, cadence requests, theme recall, role spacing, valid meters and generation-mode routing and link decoding.
- [ ] Exercise live edits, preset switching, backward/forward transport, looping, mute/solo, endings, hidden tabs and offline rendering.
- [ ] Check visuals and timeline against the actual new events and phrase boundaries.
- [ ] Compare listening examples and record regressions, performance measurements and the chosen seed fixtures. Musical scores and repetition statistics support listening; they do not replace it.
- [ ] Expose a simple profile or development control only after the underlying behaviour is useful. Keep detailed tuning in advanced controls and introduce it in the appropriate later tour stage.

The first implementation slice should complete Phase 0, start the independent percussion audit and repairs, and demonstrate one retained theme with statement, answer and return in Phase 1. Expand to shared rhythm and form only after that comparison is convincing.
