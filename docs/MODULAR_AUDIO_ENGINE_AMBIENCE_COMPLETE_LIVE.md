# Complete live Ambience facade

This new profile composes the accepted topology, loop-bank, weather-source and control-preparation components behind a synchronous Ambience-style API. It is not selected by normal Ambience, Generator, offline rendering or the prepared environment. The scoped desktop baseline and actual lifecycle checks below pass. No existing numerical kernel, accepted processor or application default is edited.

`prepareAmbienceCompleteHost(context)` is an explicit context-owner operation on a virgin suspended live context. It prepares the existing bank and topology arenas, loads the unchanged weather processor, and installs a separately generated live preparation worker. It never resumes or suspends the context. `host.create({seed, offset})` returns a synchronous facade immediately. Its `ready` and `whenIdle()` promises expose asynchronous readiness and errors. The host retains context pools; one bed's `dispose()` retires only that bed. `disposeContext()` is reserved for the context owner.

The facade provides `setShape`, `setLevels`, `setWander`, `prepare`, `connect`, `disconnect`, `start`, `stop`, `whenIdle`, `status` and idempotent `dispose`. Ordered asynchronous bookings preserve synchronous call order. At most64 are pending; the last256 receipts are diagnostics. They do not represent a captured replay DTO or a mid-render checkpoint. Controls are validated before public state changes or source/resource admission. Preparation lateness is reported as requested versus committed source frames. Asynchronous phase/bank preparation cannot recreate a source onset already in the past.

## Original control and source behavior

Loop PCM comes from the original accepted Rust preparation and retains actual29/23/18-second lengths and quantized render keys. Lazy layers capture the then-current piece offset. Loop cursors use the accepted fractional start/offset/wrap/stop implementation. Shape-only edits retain their original target times. Render-parameter changes retain the300ms debounce, one-second old/new source fade and the original arithmetic order of the old-source stop at `now + 1 + .05`. Resource references may be released while their actual cursors retain PCM, but physical cursor slots remain behind the acknowledged spatial retirement fence. Superseded unpublished preparations are canceled; exhausted capacity reports failure while the old source stays intact.

Each actual Brownian constructor owns a separate15-second wall timer. A tick captures AudioContext time before entering the asynchronous FIFO. A later period edit affects only knots not yet drawn. Switching to Sine retains the original walk and its timer. Concurrent ticks coalesce while a refill is pending. A timer or queued publication beyond the retained90-second horizon refuses explicitly; it does not fabricate missed control history. Whole-bed disconnection and independent source demand retain the accepted topology policy.

The live-only producer changes journal retention, not the Rust planner. Its fixed256-entry receipt ring permits more than4096 resources while the actual Rust RNG, next knot, birth and period remain authoritative. The old captured planner's4096-command bound and save/reload contract are unchanged. The live profile intentionally refuses captured save export. Kernel32-bit revision/resource counters and existing bounded frame/seconds limits still apply.

Weather retains three separate stereo outputs. Up to four actual old/new weather nodes may overlap behind three private unity bridges, preserving the original quick stop/start overlap without an unbounded source list. Reservation happens before asynchronous setup. Three topology bindings exist only while actual weather nodes remain. Source disposal must ACK before its private edges are removed; only the final acknowledged source permits topology cancellation of those three bindings. Missing ACK retains a quarantined source and its topology owners. Each source request map is bounded64 and readiness/retirement deadlines are at most5seconds. Startup cancellation before node creation creates no transient source. The accepted weather processor is imported unchanged, including its normal callback clock and source-frame behavior.
