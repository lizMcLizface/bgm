# Generator partial ordered mix

The opt-in `orderedMix:true` stopped-runtime profile replaces four bounded sums/sends with the accepted ordered-send Rust kernel: dry roles (6), bus sends (6), section-space sends (6), and the two post-scalar master contributors. It preserves the actual Generator, role controls, source-slot authority, Wander actors, rack DSP and application master bus. This is a partial port; it does not claim all application DSP or arbitrary old Native fan-in is equivalent.

The role order is `lead, counter, pad, bass, rhythm, perc`. Every input is one explicitly selected output of an actual retained worklet. A private RoleWander factory record certifies its fixed stereo bus zero, before its unchanged unity routing wrapper. Each of its three cohort consumers holds a real borrow. The actual trim/ambience scalar group is verified against its private clock certificate and actual program endpoints. Public metadata objects, supplied factories and foreign clocks cannot mint these capabilities.

A synchronous context-wide reservation holds all four cohort slots before any candidate construction. It shares the original four-cohort budget with independently constructed ordered-send owners. No quota is raised. A whole-runtime successor of this profile refuses before another reservation, construction, settings mutation or publication. Stopped Core/FM source-slot replacement can keep the same six Wander actors. This first profile requires existing captured private bus and space racks and excludes editable/lazy return replacement.

Fresh send constructors supply literal initial assignments. These are not reconstructed automation histories. The section-space literal is the same current atomic value read by the existing detached Native constructor, captured at that new assignment boundary. No later getter is used as a timeline replay. Dry and master slots have constant unity gain without an extra step/target prelude.

Bus controls preserve all six repeated targets, each separately deferred `currentTime`, with the original `.03` time constant. Rack patching precedes send publication. Section-space controls retain the caller's raw authored seconds and `barSeconds * .7`; bass uses `.3`, percussion `.5`, the other roles unity. Whole-cohort metadata/timeline capacity is reserved before prospective settings or move-state changes and before beat logs, held changes, visuals or note booking. Partial publication or parent callback uncertainty is terminal; no Native fallback is attempted.

The first profile pins the entire captured rack numeric recipe as well as its topology. It admits only send sequencer moves; unsupported numeric/lazy stage changes and pending voice/plan changes refuse before mutation. It never invents a gain AudioParam proxy. Ordinary Native/default Generator bodies remain exact after erasing the six marked optional branches and their import, including the separately accepted prepared Sweep branch.

The retained Native boundaries are explicit: rack input trim, its external effect chain and processed/bypass outer mixing; both rack outputs' private return Gain; the return/dry junction at `g.output`; and the global application master-bus gain/fan-in, including other app contributors. The two-input master cohort consumes actual scalar AWP outputs, skipping only the scalar factory's privately verified unity output bridges. It does not treat a Native rack return or arbitrary Native Gain as an activity authority.

Terminal shutdown first publishes the existing one-way cohort quiescence control without removing binding-owned program edges. The Main binding then removes its exact external edges. Cohorts retire serially and require actual clean SourceFence release before any provider borrow, retained clock or dependent parent owners can be destroyed. The separate parent clock lease remains held on any cohort cleanup uncertainty. The context budget remains held until whole cleanup is clean or the real context closes. A failed acquisition or late receipt never revives an already rejected ownership promise. When construction returns no owner, only the trusted constructor's private cleanup observer can certify a real `released:true`/`clean:true` receipt together with actual completed, clean, quota-released state. Missing proof or any sticky earlier cleanup failure retains dependencies; no status-shaped caller object can certify release. Actual context close releases the separately retained known clock once, even if its acquisition was pending, without changing an earlier failed disposal promise or inventing an actor ACK.

A later rack-outer port must preserve the physical two-stage graph: input trim before the external nonlinear/effect chain, followed by processed/bypass mixing. Moving trim after those effects changes the algorithm. Routing a single worklet around itself would introduce a 128-frame feedback delay. The proposed later profile therefore needs separate trim and mix actors, literal three-gain `.012` histories with distinct author timestamps, explicit processed-output/source activity and a separately reviewed budget. The current four-cohort limit cannot absorb that work implicitly.
