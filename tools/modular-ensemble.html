Six-role audio baseline · M3a / M3b / M3c / M3d

Six real instrument instances: DI-Poly lead/rhythm/pad, FM second/bass and percussion drums. Current routing uses existing worklets, local inserts, the desk mixer, shared delay/reverb and final limiter. Bridge checks the owned percussion path; Keyed adds real kick-sidechain compression. Owned FM adds two independent FM owners sharing one Wasm instance, with the same kick-keyed route. M3c also adds owned lead/rhythm/pad sharing one Wasm instance; all six source engines then have owned Rust state. M3d puts the six sources in one Rust DAG with explicit mixing and kick-keyed output. The desk route still uses existing channel inserts and mixing. All variants run on one audio rendering thread.

Play Rust mix (dry) auditions the Rust sum and kick-keyed compressor directly, omitting the desk channel and master effects.
