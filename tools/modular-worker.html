Rust graph worker prototype · M3e

Six real instruments, explicit Rust mixing and kick-keyed compression. One dedicated worker owns the complete graph; an AudioWorklet consumes a fixed PCM buffer pool. This is a dry reference mix. The desk and its defaults remain on the six-role comparison page.

Default pool: 4 × 1,024 frames, 256 KiB. Added buffering: 92.88 / 85.33 / 42.67 ms at 44.1 / 48 / 96 kHz. Missing audio becomes silence; expired blocks are discarded. No shared memory or cross-origin isolation required for this transport. Messaging can allocate and add jitter. This is one worker, not a parallel worker pool or a speedup claim.

Playback is finite: 17.5 seconds plus declared buffering. Startup failure falls back to serial with the same buffering. A failure after playback starts stops this run; a fresh serial run is available above. Live controls must target frames the worker has not rendered yet. Reset/reload creates a new generation and graph.
