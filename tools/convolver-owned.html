Portable static convolution review

The silent batch compares actual native ConvolverNode output with a portable direct-head and partitioned FFT convolver. It uses the original measured-string body impulses at six sample rates, all four mono/stereo routing combinations, an identity impulse and exact peak positions across partition boundaries up to 327,680 IR frames.

The portable kernel runs in a dedicated Worker. Its transform-boundary work has no live audio callback deadline acceptance. Only normalize=false, same-rate, one- or two-channel static impulses are supported. All and the existing reverb remain unchanged.
